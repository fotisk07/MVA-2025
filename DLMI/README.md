# Deep Learning for Medical Imaging

Coursework for the MVA Deep Learning for Medical Imaging course.

## Contents

- `challenge/`: histopathology patch classification challenge, with training, prediction, and embedding scripts.
- `paper-review/`: reviewed paper, report, and poster material.

## Setup

The challenge code uses `uv`:

```bash
cd challenge
uv sync
```

See `challenge/README.md` for data setup, KimiaNet weights, training, prediction, and submission commands.
