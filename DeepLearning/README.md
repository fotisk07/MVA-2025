# Deep Learning

Course project material for the MVA Deep Learning course.

## Contents

- `clip-reproduction/`: CLIP-style training and evaluation project in PyTorch.
- `rendus/`: final report, slides, and poster deliverables.

## Setup

The runnable code is in `clip-reproduction/` and uses `uv`:

```bash
cd clip-reproduction
uv sync
```

See `clip-reproduction/README.md` for training, evaluation, and Slurm commands.
