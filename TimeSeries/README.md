# Time Series

Practicals and project work for the MVA Advanced Time Series course.

Course page: <https://www.laurentoudre.fr/ast.html>

## Contents

- `TP/`: practical assignments and reports.
- `project/`: SoccerCPD paper review project, notebooks, source code, figures, and report material.

## Setup

Most runnable work is inside the individual TP or project folders. Use the local README when available.

For `uv` subprojects:

```bash
uv sync
```

For the SoccerCPD project:

```bash
cd project
uv pip install -e soccercpd
```
